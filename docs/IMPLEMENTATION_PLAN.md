# План реализации

> Статус на 14 сентября 2026: первый функциональный проход этапов 1–6 реализован. Следующая итерация — замена случайного сэмплера на текучий печатный растр. Исполняемый план находится в `NEXT_SESSION.md`; разделение прототипа на модули отложено до утверждения визуального алгоритма.

## Принцип разработки

Сначала строим управляемое поле яркости на простых кругах. После того как направление, волны и плотность визуально совпадут с задачей, добавляем символы и SVG. Это снижает риск спутать ошибки поля с особенностями формы модуля.

## Этап 0. Фиксация спецификации

Результат: согласованное понимание эффекта и набора контролов.

- проверить комфортный диапазон углового отклонения от базовой оси;
- выбрать 2–3 целевых формата холста для пресетов;
- определить стартовую цветовую схему;
- принять критерии MVP из `PRODUCT_SPEC.md`.

## Этап 1. Каркас локального приложения — первый проход готов

Результат: `index.html` открывается двойным кликом и показывает панель управления и пустой canvas.

- создать HTML/CSS/JS без сборщика;
- реализовать единый объект состояния;
- связать контролы с перерисовкой;
- добавить адаптивную компоновку панели и предпросмотра;
- добавить reset и отображение числовых значений.

Проверка: приложение работает через `file://`, в консоли нет ошибок.

## Этап 2. Математика свечения — первый проход готов

Результат: от выбранного угла идёт мягкое диагональное поле с волнистыми полосами.

- ввести координаты вдоль и поперёк диагональной оси;
- реализовать четыре угла-источника;
- добавить угловое отклонение веера с сохранением общей точки-источника;
- реализовать ширину, длину и мягкость затухания;
- добавить несколько модулирующих волн;
- добавить детерминированное плавное искажение.

Проверка: временный непрерывный heatmap делает форму поля очевидной и позволяет быстро откалибровать параметры.

## Этап 3. Халфтон-сэмплер — первый проход готов

Результат: поле отображается кругами, причём плотность и размер регулируются независимо.

- построить сетку потенциальных ячеек;
- реализовать seeded PRNG;
- вычислять наличие элемента через вероятность;
- отдельно вычислять размер модуля;
- добавить нерегулярность позиции;
- предусмотреть предел количества элементов для производительности.

Обязательные тестовые состояния:

- `разброс размера = 0`, плотность меняется;
- плотность постоянна, `разброс размера = 100%`;
- одинаковые параметры и seed после перезагрузки;
- все четыре направления источника.

## Этап 4. Модули — первый проход готов

Результат: одна и та же композиция рендерится разными типами элементов.

- круг;
- пользовательская строка символов;
- измерение визуальной массы символов;
- режимы последовательного, случайного и тонального выбора символа;
- загрузка и нормализация SVG;
- fallback при некорректном SVG.

Проверка: набор `0=` при одинаковом размере создаёт различимую тональную структуру за счёт распределения символов и пустот.

## Этап 5. Дизайн интерфейса — первый проход готов

Результат: инструментом удобно пользоваться как дизайнерским генератором, а не как технической демкой.

- сгруппировать контролы: «Холст», «Свечение», «Халфтон», «Модуль», «Экспорт»;
- добавить пресеты, reset и randomize;
- сделать тонкие контролы доступными с клавиатуры;
- показывать загруженную SVG-форму;
- оптимизировать частоту рендера при движении ползунка;
- добавить короткие подсказки для неоднозначных параметров.

## Этап 6. Экспорт и пресеты — первый проход готов

Результат: графику можно использовать вне генератора и воспроизводить позднее.

- PNG в полном разрешении;
- JSON export/import;
- проверка соответствия размеров;
- понятные имена файлов с seed;
- затем SVG-экспорт и прозрачность.

## Этап 7. Визуальная калибровка

Результат: стартовый пресет передаёт характер второго референса, но построен языком первого.

- подобрать ширину и затухание диагонального луча;
- настроить 2–3 волны разной частоты и амплитуды;
- проверить крупный план и уменьшенную афишную версию;
- сравнить режимы «только плотность», «только размер» и смешанный;
- сохранить 3 демонстрационных пресета.

Текущий блокер этапа: независимый случайный сдвиг и Bernoulli-прореживание создают ощущение спрея. Следующий проход использует ordered dithering и связное flow-поле; детали и критерии описаны в `NEXT_SESSION.md`.

## Очерёдность релизов

### MVP

- локальный запуск;
- canvas;
- четыре направления;
- фиксированная ось 45° и её смещение;
- плотность, размер, сетка, seed;
- круги и символы;
- PNG и JSON.

### Версия 1.1

- SVG-модуль;
- SVG-экспорт;
- несколько цветовых стопов;
- прозрачный фон;
- локальное сохранение настроек.

### Версия 1.2

- несколько слоёв свечения;
- маски и зоны исключения;
- анимация и экспорт последовательности кадров;
- ускорение через WebGL при необходимости.

## Риски и способы проверки

| Риск | Как снизить |
|---|---|
| Волны выглядят как регулярные полосы | Смешать несколько частот и добавить плавное искажение фазы |
| Плотность создаёт мерцание при настройке | Использовать фиксированный seed; менять только порог видимости |
| Символы дают непредсказуемый тон | Измерять реальную площадь штриха выбранным шрифтом |
| SVG содержит сложную разметку | Нормализовать через безопасную растровую маску для canvas; векторный экспорт отложить |
| Большой холст тормозит | Рисовать превью в пониженном разрешении, полный размер — только при экспорте |
| Разные браузеры ведут себя по-разному через `file://` | Не использовать fetch, ES-модули и CDN; тестировать Chrome и Safari с первого этапа |

## Definition of Done

Работа над MVP завершена, когда все критерии из раздела 10 спецификации проходят ручную проверку, стартовый пресет визуально демонстрирует диагональное волновое свечение, а пользователь может получить повторяемый PNG без установки дополнительных инструментов.
