# Команды рабочих сессий

Проект поддерживает две короткие команды пользователя: `start` и `finish`. Их поведение закреплено в корневом `AGENTS.md` и действует в новых сессиях Codex.

## `start`

Команда означает: восстановить контекст проекта по документации и сразу продолжить работу.

Во время `start` агент:

1. читает README, актуальное состояние, план следующей сессии, спецификацию и последнюю запись журнала;
2. проверяет файлы и сохраняет возможные пользовательские изменения;
3. запускает базовую проверку JavaScript;
4. сообщает текущую точку и ближайшую задачу;
5. приступает к первому незавершённому пункту `NEXT_SESSION.md`.

Пример:

```text
start
```

Можно сразу изменить цель:

```text
start — сегодня сначала доработаем снежинку
```

## `finish`

Команда означает: корректно закончить активную работу и подготовить передачу следующей сессии.

Во время `finish` агент:

1. завершает или безопасно останавливает текущий небольшой шаг;
2. проверяет изменённый код;
3. актуализирует состояние и следующий план;
4. добавляет запись в журнал;
5. сообщает результаты, проверки, нерешённые вопросы и первую следующую задачу.

Пример:

```text
finish
```

Команда не создаёт git-коммит и ничего не публикует без отдельного запроса.
