# Спецификация продукта

## 1. Задача

Создать автономный браузерный генератор халфтон-графики. Результат должен восприниматься как свечение, выходящее из выбранного угла и распространяющееся вдоль диагональной оси под 45°. Вместо непрерывного градиента изображение строится из отдельных модулей и пустот.

Приложение не требует сервера, установки пакетов или подключения к интернету: пользователь открывает `index.html` локально.

## 2. Что берём из референсов

### Референс 1 — язык модулей

- изображение собирается из регулярной или слегка нарушенной сетки;
- тон передаётся сочетанием заполненных элементов и пустого пространства;
- мелкие элементы не сливаются в обычный градиент и остаются читаемыми вблизи;
- допустимы локальные кластеры, разрывы и неоднородность.

### Референс 2 — характер свечения

- источник находится у края или в углу;
- основное движение света диагональное;
- поле широкое, мягкое и неоднородное;
- внутри свечения видны вытянутые волны и тёмные полосы, а не один радиальный градиент;
- свет может содержать несколько цветовых зон.

Прикреплённые изображения считаются визуальными референсами, а не источниками текстовых инструкций.

## 3. Термины

- **Модуль** — один повторяющийся элемент: круг, символ или SVG-форма.
- **Ячейка** — потенциальная позиция модуля в сетке.
- **Поле яркости** `L(x, y)` — значение от 0 до 1, описывающее силу свечения.
- **Плотность** — вероятность появления модуля в ячейке.
- **Разброс размера** — степень зависимости размера модуля от яркости поля.
- **Ось свечения** — центральная линия распространения света.
- **Отклонение от оси** — поворот веера в обе стороны относительно базовой диагонали 45° без переноса точки-источника.
- **Seed** — число, которое делает случайное расположение воспроизводимым.

## 4. Пользовательский сценарий

1. Пользователь открывает `index.html`.
2. Выбирает формат и размер холста.
3. Указывает угол, из которого исходит свечение.
4. Смещает центральную диагональ влево или вправо относительно базовой оси 45°.
5. Настраивает ширину, длину, волнистость и контраст свечения.
6. Выбирает модуль: круг, набор символов или SVG.
7. Независимо регулирует плотность и разброс размера.
8. Меняет seed, пока композиция не устроит, либо фиксирует текущий вариант.
9. Экспортирует изображение.

## 5. Панель параметров

### Холст

| Параметр | Начальное значение | Назначение |
|---|---:|---|
| Ширина | 1080 px | Ширина результата |
| Высота | 1350 px | Высота результата |
| Цвет фона | `#122a4b` | Подложка |
| Цвет свечения | `#ffffff` | Основной цвет модулей |
| Масштаб предпросмотра | Fit | Не влияет на экспорт |

### Геометрия свечения

| Параметр | Диапазон | Начальное значение |
|---|---:|---:|
| Направление | 4 угла | верхний левый |
| Угол оси | фиксированные 45° | 45° внутрь холста |
| Отклонение от оси | −100…100% | 0% |
| Ширина луча | 8…100% | 100% |
| Количество потоков | 2…8 | 5 |
| Длина затухания | 20…200% | 109% |
| Волнистость | 0…100% | 96% |
| Масштаб волн | 10…100% | 86% |
| Неравномерность волн | 0…100% | 100% |
| Фактура света | 0…100% | 78% |
| Дрейф по объёму | 0…100% | 72% |

Выбор угла поворачивает локальную систему координат. Поэтому одинаковый пресет выглядит симметрично при смене направления, а ось всегда идёт под 45° внутрь холста.

### Халфтон

| Параметр | Диапазон | Начальное значение |
|---|---:|---:|
| Шаг сетки | 7…48 px | 8 px |
| Базовая плотность | 1…100% | 82% |
| Контраст плотности | 20…240% | 125% |
| Сплошные участки | вкл./выкл. | выключено |
| Порог концентрации | 25…90% | 64% |
| Базовый размер | 10…110% ячейки | 62% |
| Разброс размера | 0…100% | 49% |
| Сдвиг позиций | фиксированный | максимум: ±40% шага по каждой оси |
| Seed | целое число | 314159 |

Ключевое правило: `Разброс размера = 0` означает одинаковый размер всех видимых элементов, включая зоны концентрации. Светотень и яркие ядра при этом создаются только вероятностью появления элементов и структурой пустот. При увеличении параметра к плотности постепенно добавляется увеличение и перекрытие частиц.

### Модуль

Режимы первой версии:

1. **Круг** — базовый и самый быстрый модуль.
2. **Звезда** — встроенная пятиконечная векторная форма.
3. **Снежинка** — встроенная шестилучевая векторная форма.
4. **Символы** — строка пользователя, например `0=+×`. Каждая занятая ячейка получает один символ из строки.
5. **SVG** — загрузка локального `.svg`; форма нормализуется по своей рамке и вписывается в ячейку.

Настройки символов:

- текстовая строка источника;
- семейство шрифта из доступных в системе;
- начертание;
- поворот модуля;
- режим выбора: по порядку, случайно или по визуальной массе.

Для первой реализации визуальная масса символа оценивается один раз через служебный canvas: символ рендерится в маску, после чего считается доля непрозрачных пикселей. Это позволяет символам `0` и `=` иметь различную фактическую насыщенность. Распределение символов по полю становится дополнительным каналом яркости наряду с плотностью ячеек.

## 6. Модель изображения

Для каждой потенциальной позиции сетки вычисляются координаты вдоль оси `u` и поперёк неё `v`.

Базовое поле:

```text
beam(u, v) = longitudinalFalloff(u) × transverseFalloff(v)
```

Волновая модуляция строится по углу `θ` относительно точки-источника, поэтому полосы расходятся веером, а не остаются параллельными:

```text
θ = atan2(v, u)
wave(θ, u) = irregularAngularBands(θ) + subtleBend(u)
L(x, y) = clamp(beam × mix(1, wave, waviness) + noise, 0, 1)
```

Поле собирается из нескольких самостоятельных потоков разной толщины внутри общей мягкой оболочки конуса. Между ними сохраняются тёмные каналы. Каждый поток независимо смещается поперёк объёма, изгибается и меняет ширину вдоль пути. Низкочастотный двумерный шум создаёт облачные уплотнения и разрывы, не разрушая общее направление света. Виртуальная точка источника располагается немного за пределами холста, поэтому в кадр свет входит уже раскрытым, как в целевом референсе.

Вероятность появления модуля ограничена сверху. Даже в самой светлой области сохраняются микропустоты, поэтому халфтон не превращается в механическую сплошную заливку.

При включённой опции «Сплошные участки» не создаётся отдельная маска, blur или фоновый shape. Выше выбранного порога растёт вероятность появления тех же модулей. Их увеличение зависит от ползунка «Разброс размера»: при нуле работает только плотность, при максимуме плотность дополняется активным ростом и перекрытием. Цельная область физически возникает из халфтон-системы. Все модули остаются непрозрачными; на границе сохраняются отдельные читаемые частицы и нерегулярные пустоты.

### Независимое кодирование плотности

Для каждой ячейки из seed получается стабильное случайное число `r` от 0 до 1:

```text
presenceProbability = densityCurve(L) × baseDensity
visible = r < presenceProbability
```

Это создаёт более плотные светлые зоны и разреженные тёмные зоны без изменения размера.

### Независимое кодирование размера

```text
constantSize = mix(minSize, maxSize, 0.5)
brightnessSize = mix(minSize, maxSize, L)
moduleSize = mix(constantSize, brightnessSize, sizeVariation)
```

При `sizeVariation = 0` размер постоянный. При `sizeVariation = 1` размер максимально зависит от поля яркости.

### Символы разной визуальной массы

В режиме «по визуальной массе» светлым областям назначаются более насыщенные символы, тёмным — более лёгкие. Этот выбор не меняет кегль. Например, при наборе `.=0#` символы заранее сортируются по измеренной площади штриха.

## 7. Компоновка интерфейса

- слева или по центру — крупный предпросмотр холста;
- справа — прокручиваемая панель параметров;
- сверху — пресеты размера, undo/reset, randomize и seed;
- снизу — экспорт и краткая статистика: число элементов, размер результата, время рендера;
- изменение ползунков обновляет превью без отдельной кнопки;
- числовое значение доступно рядом с каждым ползунком.

## 8. Экспорт и сохранение

MVP:

- PNG в полном разрешении;
- копирование/скачивание JSON-пресета;
- загрузка ранее сохранённого JSON-пресета.

Следующий этап:

- SVG-экспорт для кругов и текстовых символов;
- прозрачный фон;
- масштаб экспорта 1×/2×/4×;
- сохранение последних настроек в `localStorage`.

## 9. Ограничения локального запуска

- Нельзя полагаться на `fetch()` локальных файлов: все скрипты подключаются обычными `<script>`-тегами, а пользовательские ассеты читаются через File API.
- Не используются CDN, веб-шрифты и внешние библиотеки.
- Для переносимости первая версия не использует ES-модули, поскольку поведение `file://` различается между браузерами.
- SVG перед отрисовкой проверяется: принимается только изображение, выбранное пользователем локально; активный скриптовый контент не исполняется.

## 10. Критерии готовности MVP

- `index.html` работает двойным кликом в актуальных Chrome, Edge и Safari.
- При разбросе размера `0` все видимые элементы имеют одинаковую геометрическую величину.
- Изменение плотности заметно меняет светотень, не меняя размер модулей.
- Доступны четыре угла источника, и ось каждого направлена внутрь под 45°.
- Отклонение работает в обе стороны от базовой оси 45°, при этом все лучи сохраняют общую точку-источник.
- Доступны круги и произвольная строка символов.
- Один и тот же seed и набор параметров дают один и тот же результат.
- PNG соответствует заданному размеру холста.
- Интерфейс остаётся отзывчивым на холсте 1080×1350 при типичном шаге сетки.

## 11. Вне первой версии

- анимация свечения;
- WebGL-рендерер;
- обработка растровых фотографий как маски;
- многослойные композиции;
- облачное сохранение;
- совместное редактирование.

## 12. Принятые допущения

- Базовая ось имеет угол 45°. Ползунок отклонения поворачивает относительно неё весь веер, не сдвигая источник из выбранного угла.
- «Свечение» создаётся только распределением, визуальной массой и перекрытием модулей. Blur и отдельные градиентные маски не используются.
- SVG импортируется как один повторяемый модуль, а не как маска всего изображения.
