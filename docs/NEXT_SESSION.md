# План следующей сессии

Главная цель: проверить печатный SVG в Adobe Illustrator и довести экспорт до надёжного дизайнерского результата. Генератор по-прежнему должен работать локально через `file://` без сборки, сервера и сетевых зависимостей.

## Первый незавершённый шаг

- [ ] Открыть в Illustrator SVG форматов A4 (210 × 297 мм), DL (220 × 110 мм) и ручного размера (например, 250 × 340 мм). Установить единицы документа в миллиметры и проверить точные размеры артборда. Если Illustrator трактует размеры иначе, исправить SVG-метаданные и добавить регрессионный тест.

## Затем

- [ ] Сравнить SVG с фоном и прозрачный PNG одного seed и формата: положение частиц, направление луча, цвета, прозрачность. Проверить круг, звезду и контуры текста `ЭНКО`.
- [ ] Проверить экспорт локально загруженного SVG-модуля: композицию, сохранение вектора, размер файла и отсутствие внешних ресурсов. Если файл слишком велик из-за повторения модуля, вынести форму в `<defs>` и использовать `<use>`, не меняя видимого результата.
- [ ] Проверить крупные печатные форматы и плотную сетку на время генерации и размер файла; при необходимости добавить ненавязчивый индикатор экспорта или ограничение с понятным сообщением.
- [ ] Отдельно согласовать, нужны ли вылеты, клапаны и выкройки пакетов. Текущие пресеты пакетов задают только лицевую сторону.

## Проверка после изменений

```sh
node --check src/app.js
node --test tests/svg-export.test.js
git diff --check
```

Проверить локальное открытие `index.html`, прозрачный PNG, SVG с фоном и воспроизводимость композиции по seed. Убедиться, что Illustrator видит буквы как векторные контуры, а не текст.
