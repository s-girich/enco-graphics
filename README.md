# ENKO Halftone Glow Generator

Локальный генератор графики, который запускается простым открытием `index.html` в браузере. Он собирает мягкое диагональное свечение из дискретных халфтон-элементов: кругов, текстовых символов или пользовательских SVG-форм.

## Статус

Интерактивный прототип запускается открытием `index.html`, строит свечение из отдельных растровых модулей, принимает локальный SVG-модуль и экспортирует прозрачный PNG, векторный SVG и JSON-пресет. Требования и модель эффекта описаны в [docs/PRODUCT_SPEC.md](docs/PRODUCT_SPEC.md), последовательность развития — в [docs/IMPLEMENTATION_PLAN.md](docs/IMPLEMENTATION_PLAN.md).

Актуальная точка проекта зафиксирована в [docs/CURRENT_STATE.md](docs/CURRENT_STATE.md), ближайшие проверки — в [docs/NEXT_SESSION.md](docs/NEXT_SESSION.md).

## Команды сессии

- `start` — прочитать проектную документацию, проверить состояние и начать первый пункт следующего плана;
- `finish` — завершить текущий шаг, выполнить проверки и подготовить документацию для следующей сессии.

Подробный протокол: [docs/SESSION_PROTOCOL.md](docs/SESSION_PROTOCOL.md). История решений: [docs/SESSION_LOG.md](docs/SESSION_LOG.md).

## Запуск

1. Откройте `index.html` двойным кликом в Chrome, Safari или Edge.
2. Настройте свечение в правой панели.
3. Для печати выберите формат или укажите ширину и высоту в миллиметрах. Нажмите «Скачать SVG»; размер артборда записывается в `mm`. PNG выгружается отдельно, без фона.

Сервер и установка зависимостей не нужны.

## Основная идея

Яркость в каждой точке поля преобразуется в два независимых визуальных канала:

- плотность: в светлых областях появляется больше элементов, в тёмных — больше пустот;
- размер: при нулевом разбросе все элементы равны, при увеличении параметра светлые и тёмные области сильнее различаются по размеру модулей.

Так символы с разной визуальной массой, например `0` и `=`, смогут формировать свечение за счёт частоты появления, не требуя обязательного масштабирования.

## Предполагаемый стек

- HTML, CSS и JavaScript без сборки и внешних зависимостей;
- Canvas 2D для интерактивного предпросмотра и PNG;
- сериализуемое состояние для повторяемой генерации;
- импорт локального SVG через `<input type="file">`;
- запуск по протоколу `file://` двойным кликом по `index.html`.

## Реализовано в первом подходе

- четыре угла-источника и фиксированная ось 45°;
- угловое отклонение от оси, ширина и длина луча;
- объёмный световой конус с широкими неоднородными массами, облачной фактурой и микропустотами;
- независимая плотность и разброс размера;
- круги, звёзды, снежинки, тонально сортируемые символы и импорт SVG;
- воспроизводимый seed;
- экспорт PNG и JSON-пресетов;
- SVG-экспорт с физическим размером в миллиметрах и пресетами A4, A5, A6, DL, C5, визитки и лицевой стороны пакетов;
- опциональная концентрация модулей в ярких ядрах — при нулевом разбросе только плотностью, при большем значении также размером и перекрытием;
- управление объёмом через прозрачность и цветовые полутона, распределённые по волнам.

Стартовое состояние соответствует пресету `enko-halftone-314159 (4).json`: горизонтальный холст 1920×1080, синий фон, белые символы `ЭНКО` и усиленные объёмные волны. Сдвиг элементов зафиксирован на максимуме и не показывается в интерфейсе.
